## Contributing

This repository is generated automatically please do **not** open pull requests against `README.md`, because every change is overwritten on the next refresh (within 24 hours).

### Know a good source of free configs? Tell us!

If you know any source (Telegram channel, GitHub repo, website, subscription URL, etc.) that you'd like to see added to **Abc Configs**, please [**open a new issue**](https://github.com/freeVpnMan/top-free-vpn-proxy-list/issues/new?title=New%20source%20suggestion&labels=new-source&body=Source%20URL%20(Telegram%20%2F%20GitHub%20%2F%20website)%3A%0A%0AWhy%20it's%20a%20good%20source%3A%0A%0AAny%20extra%20notes%3A%0A) and describe the source there.

In the issue, please include:

1. **Source URL** e.g. `https://t.me/some_channel`, a GitHub repo link, or a subscription URL.
2. **Type of source** Telegram channel / GitHub repo / website / subscription / other.
3. **Why it's worth adding** e.g. fresh daily, many working nodes, specific country, etc.
4. **Anything we should know** language, posting frequency, login required, etc.

You can browse existing suggestions in the [Issues tab](https://github.com/freeVpnMan/top-free-vpn-proxy-list/issues). Duplicates are fine please still open an issue if you're not sure, we'll de-duplicate on our side.
